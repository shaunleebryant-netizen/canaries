# Error 1102 (Worker exceeded resource limits), 2026-10-08 (t580u)

- Owner hit 1102 on iPad Safari at 17:52 NZ (Ray a47288f57d82f463).
- `wrangler tail` showed `exceededCpu` ("Worker exceeded CPU time limit") on `/media/canary-v1.2-720p.mp4`.
  The old Next route did `arrayBuffer()` on the 24.9 MB MP4 for every request (~250 ms CPU, 25–50 MB each).
  Safari sends several Range requests per play. When the isolate was killed, requests sharing it failed too (503s on pages).
- Fix (Worker 10fc19d9): `worker-entry.mjs` (wrangler `main`) answers `/media/*` before Next, using `src/lib/mediaRange.mjs`.
  - Ranges from byte 0 pass the native ASSETS stream straight through.
  - Later ranges come from the Cache API (`match()` returns 206 natively).
  - Video CPU is now 0–2 ms per request.
- Video replaced? Update `size` in `MEDIA_FILES` (`src/lib/mediaRange.mjs`). It is also the cache key.
- Local `wrangler dev` needs `--compatibility-date 2026-05-03` (the local runtime is older than the deployed date).
- Residual: cold page renders measure 150–300 ms CPU (`/members/login`, `/indicators`). Check the account's Workers plan and CPU limit in the dashboard.
